PLANNING DOJO CLUB V40.0

Déploiement GitHub Pages
1. Supprimer les anciens fichiers du dépôt, sauf ceux que vous souhaitez conserver ailleurs.
2. Envoyer TOUS les fichiers de ce dossier à la racine du dépôt, pas le ZIP lui-même.
3. Vérifier que index.html, app.css, app.js et planning-data.js sont visibles au même niveau.
4. Attendre le déploiement GitHub Pages.
5. Ouvrir https://gdefer4-dot.github.io/dojo-planning/?v=400

Installation iPhone
- Ouvrir dans Safari.
- Toucher « Installer Planning Dojo Club ».
- Puis Partager > Sur l’écran d’accueil > Ajouter.
- Supprimer l’ancien raccourci avant de réinstaller pour renouveler le logo et le nom.

Architecture V40
- index.html : structure
- app.css : mise en page
- planning-data.js : données des cours
- app.js : fonctionnement
- manifest.webmanifest + service-worker.js : installation PWA et hors connexion
