DOJO PLANNING V32
=================

1. Ouvrez planning-affiche.html pour gérer les plannings et les fiches.
2. Le bouton « Exporter la page QR » crée désormais un index.html marqué V32.
3. Le fichier exporté contient les horaires actuellement enregistrés dans le navigateur,
   les coachs, les descriptions et la nouvelle présentation des fiches mobiles.
4. Sur GitHub, remplacez l'ancien index.html par le nouveau fichier portant exactement ce nom.
5. Un index.html prêt à tester est également fourni dans ce dossier.

Nouveautés mobiles :
- fiches plus visuelles avec en-tête coloré et icône ;
- coach, horaire, lieu et intensité présentés sous forme de cartes ;
- description mise en valeur ;
- tous les créneaux de la même activité regroupés dans la fiche ;
- badge V32 permanent pour vérifier la version publiée ;
- aucun bouton d'inscription.

La mise en page imprimée n'a pas été modifiée.
